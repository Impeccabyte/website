# Vendor marks (`/integrations`)

Small square marks rendered inside the white logo tiles on `/integrations`.
Filenames match `Integration.logo` in `lib/integrations.ts`.

## ⚠️ These are placeholders

They were captured from Google's favicon service
(`https://www.google.com/s2/favicons?domain=<domain>&sz=64`) — the same source the
design prototype used — and are **self-hosted here** rather than hot-linked, so the
page makes no third-party request at render time.

They are *favicons*, not licensed brand assets. **Before a brand-sensitive launch,
replace each file with the vendor's official mark** from their press/brand kit, at
the same path and basename (no code change needed). A few are only 16×16 at source
and look soft when scaled — `magento`, `opencart`, `ingenico` — so start with those.

Trademark usage on the page is scoped by the notice in `lib/integrations.ts`
(`trademarkNotice`), rendered under the closing CTA. Keep it verbatim.
